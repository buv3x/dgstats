# General Information

This application gathers hole-by-hole scores and calculates and displays statistics for Lithuanian PDGA tournaments.
Lithuanian PDGA tournaments used hole-by-hole scores from PDGA Live sporadically from late 2021 through 2022. Since 2023, every tournament has included them, so the statistics cover this period.
At the moment, [competition_count] competitions have been processed, and [players_count] players have included scores. The latest included competition is [latest_competition].

The application uses players' PDGA ratings and mechanisms analogous to those used in PDGA rating calculations. It combines results for each hole across multiple tournaments in the style of DGMetrix.
A hole can have multiple variations when its layout changes significantly - for example, because of a new basket or tee, or changed out-of-bounds (OB) rules. These variations are tracked separately.

# Course Stats

This section has two parts, and the filters at the top affect both. You can select a course from a list (courses are sorted by the number of recorded results) and specify a rating range. Either or both rating limits can be left blank. The charts display statistics for the selected rating range, or for all ratings when no range is selected.

The table shows the percentage of each possible score for every hole variation. Note that par is not defined anywhere, although it can usually be inferred from the numbers.

The chart introduces two measurements, VAR and SPR. Each point represents a hole variation for the selected course.
VAR measures how variable scoring is on a hole variation. Higher values indicate a wider range of possible results, usually because of factors such as difficult out-of-bounds areas or deep woods; lower values indicate a more straightforward hole.
SPR measures how strongly scoring separates players by rating. Higher values indicate a longer, more difficult hole where skill level makes a greater difference. Lower values indicate that scores are less correlated with rating, usually because the hole is simple or results are more random.

# Hole Stats

The chart in this section shows how a hole variation plays across the rating range.
The SPR value in the previous section measures scoring separation using all results. Here, SPRW is calculated for a particular rating range. A peak in the chart indicates the rating range with the greatest scoring separation - the range in which the hole variation is most challenging and therefore its target audience.
A solid line indicates that the rating range has enough recorded results. A dashed line indicates fewer results and lower confidence. Unconnected dots indicate even fewer results; the chart should mostly be ignored in those areas.

# Personal Stats

The other calculations effectively produce a separate PDGA-rating-like value for each hole variation. Although it is not an official PDGA rating, it is calculated in a similar manner and can be used to estimate each person's average rating on each hole variation.
After you select a player, the table shows that player's average rating for each hole variation and lists the results.
Keep in mind that a player's rating becomes more reliable as the player records more results and as more results are recorded for the hole variation in general. A hole variation played only a few times - especially on a less frequently played course - can produce extreme values. You can filter these out using the course and number-of-plays filters.
