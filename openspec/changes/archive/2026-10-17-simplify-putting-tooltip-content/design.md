## Context

The Personal putting renderer uses two tooltip builders: one for round-based highlights such as Most C2+ and Best C1x, and one for hole-based Longest throw-in occurrences. Both currently prepend the metric/value and a section heading to the useful context lines. The tooltip mechanism itself is shared and already supports pointer and keyboard access.

## Goals / Non-Goals

**Goals:**

- Make tooltip content consist only of competition/round context lines.
- Keep each matching round or occurrence on its own line.
- Include the hole number for Longest throw-in occurrences.
- Preserve visible values, tooltip triggers, and accessible labels.

**Non-Goals:**

- Changing exported statistics or occurrence data.
- Changing tooltip positioning, styling, or interaction behavior.
- Removing metric/value context from the trigger's accessible `aria-label`.

## Decisions

Update both existing tooltip formatting functions in `docs/app.js`. The round-based formatter will return one `[competition] [round]` line per descriptor. The Longest throw-in formatter will return one `[competition] [round] — Hole [number]` line per occurrence. No heading, metric label, displayed value, or section label will be included in `data-tooltip`.

The accessible `aria-label` remains generated by `puttingValueLine`, so screen-reader users still receive the statistic name and value while the visual tooltip stays concise.

## Risks / Trade-offs

- [A tooltip with one line has no explicit metric context] → The trigger's visible label and accessible `aria-label` retain the metric context.
- [Long competition/round labels remain wide] → Reuse the existing tooltip container and line wrapping behavior.
